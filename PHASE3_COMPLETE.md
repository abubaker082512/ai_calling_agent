## 🔍 **How It Works**

### 1. Call Starts
- AI enabled with configuration
- System prompt loaded
- Greeting generated by LLM

### 2. User Speaks
- STT transcribes speech
- Transcript added to conversation history

### 3. AI Processes
- Full conversation history sent to LLM
- Context-aware response generated
- Response added to history

### 4. AI Responds
- TTS speaks AI-generated response
- Loop continues

### 5. Special Cases
- **Low confidence:** Asks to repeat
- **Escalation keywords:** Transfers to human
- **Goodbye keywords:** Ends call gracefully
